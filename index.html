How to

- Adjust the audio channel of all film files in the selected bin to mono before creating the sequences (SIFT + G).
- Select a bin in the project panel containing the film files.

- Click on the button to execute it.

Insert clips from selected bin to active sequence

Features

- Inserts every movie clip from the selected bin into the active sequence, one after another.
- The in point of each clip is calculated as a percentage of the clip's total duration.
- The out point is set to exactly "Clip length" seconds after the in point.

How to

- Select a bin in the project panel containing the movie clips to insert.
- Make sure a sequence is open and active in the timeline.
- Set the clip length (in seconds) to use for every inserted clip.
- Set the start position slider to choose where in each source clip the in point should be placed (as a percentage of its duration).
- Click the button to insert all clips from the bin into the active sequence, one after another.

Extract and bulk export Clips from current Timeline (via AME)

Features

- Extracts and exports each indivual clip from the selected video track within the In/Out range of the active sequence.
- Uses a QuickTime container with medium h264 preset.
- Audio is always included.

How to

- Set option to export entire video layer stack or just the selected track.
- If only one video track is selected, set the video track name to extract (e.g. "Video 1").
- Set the export folder path or use Browse to pick one.
- (optional) Set in and out points in the active sequence to define the range to export from. If no in/out points are set, the whole sequence will be exported.
- Click export button to send all clips to AME.
