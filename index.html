Features

- Creates sequences from seleced bin
- Dynamic FPS adjustment of sequence
- Add suffix "_dnx" at the end of the sequence name

How to

- Adjust the audio channel of all film files in the selected bin to mono before creating the sequences (SIFT + G).
- Select a bin in the project panel containing the film files.
- Create a new black frame clip in the project panel and enter its name in the input field.
- Import the .mogrt file for the film-data-slide into the project panel and enter its name in the input field.
- Click on the button to execute it.

Already existing sequecnes with the same name will be skipped.

Features

- Exports all sequences from selected bin via Adobe Media Encoder
- Uses a predfined export preset currently set to "KiPro Export ver2.5"

How to

- Select a bin in the project panel containing the sequences to export.
- Set the export folder path or use Browse to pick one.
- Click Export Sequences to ME to queue all sequences in the bin to Adobe Media Encoder.
